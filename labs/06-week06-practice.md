# Week 6 Practice — Trade-offs & scoring rubrics (2 h)

**Course:** Analysis and Assessment of Design Quality (MSc SE)  
**Pairs with:** `../sources/06-week06-lecture.tex`

---

## Goals

- Build an evidence-bearing trade-off table  
- Score two options with a shared rubric  
- Calibrate in a triad; document dissent  

---

## Options (fixed)

Reuse **ExpenseApprovals** Designs **A** and **B** from Week 5 (or lecturer substitutes).  
Prioritized attributes: Maintainability (M1), Reliability (R1), Security (S1), Ops cost.

---

## Part A — Trade-off table (40 min)

| Option | Maintainability | Reliability | Security | Ops cost |
|--------|-----------------|-------------|----------|----------|
| A | | | | |
| B | | | | |

Use ++ / + / 0 / − / −− **and** a short evidence note per cell.  
Write a **recommendation** (pick + give-ups + conditions + reversibility note).

---

## Part B — Rubric scoring (40 min independently)

Score **each** design 1–4 on:

| Criterion | A score | A evidence | B score | B evidence |
|-----------|--------:|------------|--------:|------------|
| Scenario alignment | | | | |
| Boundary health | | | | |
| Smell handling (as designed) | | | | |
| Metrics literacy (if metrics provided) | | | | |
| Trade-off / decision quality (of the *pack*, if author-supplied) | | | | |
| Presentation clarity | | | | |

*If you are evaluating lecturer packs rather than student packs, treat “trade-off quality” as how well the **option** supports explicit decisions you would record.*

---

## Part C — Triad calibration (35 min)

1. Compare scores; discuss gaps >1 level.  
2. Update scores if persuaded.  
3. Document any **unresolved dissent** (3–5 lines).

---

- [ ] Two scored rubrics with evidence  
- [ ] Disagreement note (or “full agreement”)
